# Jimmy Media Planning

Treat creative planning and media generation as separate steps. A text model can draft a brief; only a compatible image or video generation endpoint can create the asset.

- Record output use, aspect ratio, duration, resolution, visual references, subject continuity, and any audio requirements.
- Write prompts around subject, action, setting, composition, camera, lighting, style, and constraints. Keep reference assets and rights provenance attached to the brief.
- Check the exact service model ID, supported inputs, output limits, and current route price before submitting a generation request.
- Treat image/video generations as potentially billable and non-deterministic. Do not run one unless the user requested generation and its cost/side effects are authorized.
- Review the output for factual product details, unwanted marks, rights, accessibility, and platform specifications before publishing.
