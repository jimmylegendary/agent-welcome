# Jimmy Skills starter

These are original, small instruction starters for common planning and implementation work. They are not tools, API credentials, or guarantees that an external service is available. Read the core skill, then install only the domain folders you want Codex to discover.

## Install

Copy selected skill folders into `$CODEX_HOME/skills/` or `~/.codex/skills/`. Keep the folder name aligned with the `name` field in each `SKILL.md`. Restart or start a fresh Codex session if your runtime does not discover new skills immediately.

## Included skills

- `jimmy-core`: truth, authorization, and evidence boundaries for all tasks.
- `jimmy-web-mobile`: web and Flutter application work.
- `jimmy-browser-automation`: public-page extraction and bounded browser work.
- `jimmy-marketing-retail`: marketing copy and retail catalog content.
- `jimmy-game-planning`: game systems and implementation plans.
- `jimmy-media-planning`: image and video briefs, separated from LLM planning.

The files were written for this bundle and do not copy private local skills or third-party skill text. Check any external skill's license and provenance before adapting it.
